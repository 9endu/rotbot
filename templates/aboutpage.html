About RotBot

Revolutionizing fruit freshness detection with IoT and AI

About Us

We are a team of aspiring innovators focused on building intelligent solutions to real-world problems using cutting-edge technologies. Our current project is an IoT-Based Fruit Freshness Detection System, developed to address the challenge of food spoilage by determining the freshness level of fruits in real time.

Project Objective

The goal of this project is to design a system that can:

  • Detect the freshness of fruits using sensor data.
  • Minimize fruit waste by providing real-time classification of fruit condition.
  • Help vendors and consumers make informed decisions about fruit quality.

Sensor Setup

Our system uses a carefully selected array of sensors and microcontrollers:

MQ4 Gas Sensor

Detects the ethylene gas emitted by ripening fruits.

DHT11 Sensor

Captures temperature and humidity data.

Arduino Uno / NodeMCU

Acts as the core controller and data transmitter.

Machine Learning Integration

We use supervised machine learning models trained on sensor data to classify fruits into three freshness categories:

Fresh
Mid-Fresh
Spoiled

MLP (Multi-layer Perceptron)

A neural network used for pattern recognition and classification.

XGBoost

A gradient boosting algorithm that provides high accuracy in predictive modeling.

Model Accuracy

MLP Accuracy 93.2%
XGBoost Accuracy 95.7%
